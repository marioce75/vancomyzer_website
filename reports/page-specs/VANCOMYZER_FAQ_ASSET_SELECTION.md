# Vancomyzer FAQ Asset Selection

## Purpose
Select the exact assets to use on the Phase 1 FAQ page so implementation can proceed without ambiguity.

## Selected FAQ asset bundle

### 1. Core FAQ item shortlist
Selected FAQ items:
1. What is AUC-guided vancomycin dosing?
2. How is Bayesian dosing different from traditional PK dosing?
3. Why might AUC interpretation differ from trough-based reasoning?
4. Why does transparency matter in a vancomycin dosing tool?
5. What should clinicians review before accepting a recommendation?
6. Can documentation-ready summaries improve workflow?

Primary source:
- reports/faq/VANCOMYZER_FAQ.md

Rationale:
- covers the strongest first-order workflow questions
- covers trust/review behavior
- covers documentation/workflow value
- stays concise enough for Phase 1

### 5. CTA family for FAQ page
Use this CTA family consistently:
- Review a sample case
- See how the workflow is explained
- Review a documentation-ready summary

Rationale:
- consistent with Phase 1 CTA family
- keeps the FAQ educational and exploratory
- avoids hard-sell conversion language

## Explicit non-selections
Do not use:
- CASE-003 as the primary FAQ support case
- long clinical-note export as the primary FAQ support example
- pricing/institutional CTA language
- large bundles of secondary FAQ items
- feature-page or comparison-page language

## Reuse strategy
The FAQ page should reuse:
- the shared CTA family
- the same general-purpose case used on the homepage where practical
- the same general-purpose export example used on the homepage where practical

This reduces implementation ambiguity and keeps Phase 1 coherent.

## Implementation notes
- FAQ should stay concise and practical
- support links should help users go deeper without bloating the page
- the page should answer first-order questions, then direct users toward trust-building resources
