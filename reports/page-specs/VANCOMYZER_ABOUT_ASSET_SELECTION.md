# Vancomyzer About Page Asset Selection

## Purpose
Define the exact asset bundle used on the Phase 1 About page.

The goal is to explain mission and philosophy while reusing existing assets from the homepage and trust pages.

---

## 1. Mission language source

Primary source:

- reports/about/VANCOMYZER_ABOUT_PAGE.md

Key message themes:

- transparency in dosing interpretation
- clinician-readable workflow support
- interpretability and visible assumptions
- documentation clarity for communication

Rationale:

- aligns with trust/evidence messaging
- avoids marketing-style positioning
- supports clinician credibility

---

## 2. Supporting sample case

Selected case:

CASE-001 — Stable adult with preserved renal function

Source:

- reports/case-library/VANCOMYZER_CASE_LIBRARY.md

Rationale:

- best general-purpose case
- already used on the homepage
- easiest example for explaining the workflow

Usage:

- optional link: "Review a sample case"

## 3. Supporting documentation example

quick summary export

- reports/documentation/examples/INDEX.md

- concise

- reinforces documentation clarity without complexity

Usage:

- optional link: "Review a documentation-ready summary"

## 4. Trust-supporting content link

Primary reference:

Trust & Evidence page

Sources:

- reports/trust-evidence/VANCOMYZER_VALIDATION_AND_CLAIMS_GUARDRAILS.md

---

## 5. CTA family

Use the same CTA family used across Phase 1:

- Review a sample case
- Explore the workflow
- Review a documentation-ready summary
- Explore the Trust & Evidence page

Rationale:

- maintains consistency across pages
- keeps conversion demo-first

---

## Explicit non-selections

Do not include:

- institutional sales messaging
- marketing slogans
- pricing references
- competitor comparisons
- complex case demonstrations

---

## Reuse strategy

The About page should reuse:

- homepage case example (CASE-001)
- homepage export preview
- trust/evidence messaging
- shared CTA family

Rationale:

- reduces implementation complexity
- keeps Phase 1 coherent
- prevents asset sprawl

---

## Implementation notes

- keep the page concise
- mission and philosophy should remain practical
- prioritize clinician credibility over brand storytelling
