# Vancomyzer MVP Website Spec

Generated: 2026-03-12T23:48:11.685496Z

## Purpose
Define the minimum viable website build for Vancomyzer Phase 1.

## Phase 1 objective
Create a credible, trust-building website that explains what Vancomyzer is, why it matters, and how a first-time visitor should explore it.

## Required MVP pages

### 1. Homepage
- hero headline and subheadline
- positioning summary
- trust/transparency highlights
- sample case preview
- CTA to explore workflow or review a case

### 2. About page
- mission
- product philosophy
- clinician-first design principles
- who it is for

### 3. Trust and evidence page
- transparency principles
- what users should review
- limitations/caution framing
- evidence-aware messaging

### 4. FAQ page
- core Bayesian/AUC questions
- transparency and workflow questions
- documentation and interpretation questions

### 5. Contact / institutional page
- who should contact
- what evaluators can review
- demo-first CTA path
- evaluation/contact CTA

## Recommended MVP reusable sections

- hero section
- trust highlights block
- case preview block
- CTA block
- FAQ preview block
- documentation/export preview block

## Required supporting assets

- homepage copy
- about-page copy
- trust/evidence copy
- FAQ copy
- sample case summaries
- sample export examples

## What can wait until later phases

- full resource hub
- full SEO page set
- comparison pages
- newsletter infrastructure
- webinar/event program
- outreach and demo deck expansion

## MVP success criteria

- a first-time visitor understands what Vancomyzer is
- trust and caution are visible
- the site offers a clear next step
- the site has at least one strong demo/case path
- messaging stays concrete and evidence-aware

## Messaging guardrails

- avoid unsupported claims
- keep language clinician-readable
- emphasize transparency, interpretability, and workflow usability
- do not overstate validation or superiority
