## Reuse strategy

### Asset reuse priorities
1. Reuse one strongest general-purpose case across homepage, FAQ, and about.
2. Reuse one strongest trust-building case on trust/evidence and possibly contact/institutional.
3. Reuse one strongest general-purpose export example across homepage, FAQ, and about.
4. Reuse one strongest evaluator-facing export example on contact/institutional.
5. Reuse the same CTA family across all five Phase 1 pages.

### Rationale
- reduces implementation ambiguity
- keeps Phase 1 coherent
- minimizes unnecessary asset sprawl
- supports consistent trust-building across pages

## Missing asset notes
No major category appears missing. The main remaining work is not asset creation, but exact asset selection.

## Implementation guidance
- do not create page-specific variants until the shared-asset bundle is finalized
- prefer reuse over customization
- let page implementation specs determine section placement, not new content invention
