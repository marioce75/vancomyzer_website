# Vancomyzer Output Panel Wireframe

## Top summary card
- Recommended regimen
- Estimated AUC
- Estimated trough
- Target range status
- Last updated timestamp

## Secondary interpretation card
- Why this recommendation was made
- Main influencing factors
- Key assumptions

## Expandable technical details
- Input values used
- PK method used
- Bayesian / traditional logic note
- Calculation details
- Scenario notes

## Safety / caution card
- Data limitations
- Unstable renal function warning
- Sparse level warning
- Fallback/default assumption warning

## Action options
- Recalculate
- Compare scenarios
- Review inputs
- Copy summary
- Export documentation-ready note
