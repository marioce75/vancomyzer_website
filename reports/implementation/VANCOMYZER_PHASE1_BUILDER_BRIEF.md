Follow these rules:

- Build only the five Phase 1 pages
- Reuse the shared assets
- Do not invent new asset variants

- comparison pages
- feature pages
- resource hub
- newsletters
- lead magnets

- outreach assets

These belong to later phases.

# Builder success criteria

Implementation is successful when:

- all five pages exist
- shared assets are reused correctly
- navigation matches the sitemap
- cross-links match the defined plan
- CTA wording is consistent
- claims guardrails are respected
