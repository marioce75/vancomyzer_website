# Vancomyzer Phase 1 Site Map and Navigation — Refined

## Purpose
Define the simplest credible Phase 1 site structure for Vancomyzer so first-time visitors can understand the product, build trust, and find the next step without navigation overload.

## Final Phase 1 page set
1. Homepage
2. Trust & Evidence
3. FAQ
4. About
5. Contact / Institutional

## Recommended primary navigation
- Home
- Trust & Evidence
- FAQ
- About
- Contact

## Navigation rationale
- Keep the top navigation minimal.
- Give Trust & Evidence a top-level slot because trust is a core differentiator.
- Keep FAQ top-level because it reduces first-order confusion quickly.
- Keep About and Contact available but secondary in importance to trust and workflow exploration.
- Do not overload top navigation with future Phase 2/3 pages.

## “How it works” guidance
Phase 1 should not require a separate top-level “How it works” page.

Instead:
- homepage should carry the first workflow explanation
- sample case CTA should act as the strongest demo-first exploration path
- Trust & Evidence should reinforce how the workflow should be reviewed

This keeps navigation simpler and avoids premature page sprawl.

## Recommended footer navigation
- About
- Trust & Evidence
- FAQ
- Contact
- Review a sample case
- Review a documentation-ready summary

## Refined first-visit path
Recommended first-visit sequence:

1. Homepage
2. Trust & Evidence or sample case
3. FAQ or documentation-ready summary
4. Contact / evaluation path

Rationale:
- users should encounter trust before deeper commitment
- users should see one concrete example before evaluator/contact asks
- FAQ should remain a support path, not the primary landing destination

### Trust & Evidence should link to:

- Contact / Institutional

### FAQ should link to:
- Trust & Evidence
- sample case
- documentation-ready summary

### About should link to:
- sample case
- Trust & Evidence
- documentation-ready summary

### Contact / Institutional should link to:
- sample case
- documentation-ready summary
- Trust & Evidence
- direct contact/evaluation CTA

## Explicit exclusions
Do not include in Phase 1 primary nav:
- comparison pages
- SEO landing pages
- resource hub
- pricing pages
- feature pages
- newsletter or lead-magnet entry points
- webinar/events

These can exist later, but should not complicate Phase 1 navigation.

## Success criteria
The sitemap is successful if:
- top navigation remains simple
- first-time visitors can find trust-building content quickly
- demo-first exploration paths are clear
- no Phase 2/3 clutter appears in core navigation
- each Phase 1 page has at least one useful next-step path

## Implementation guardrails
- keep the top nav limited to the 5 core page categories
- prioritize trust and example-based exploration
- avoid dead-end pages
- use footer and in-page CTAs for deeper exploration instead of expanding top nav
