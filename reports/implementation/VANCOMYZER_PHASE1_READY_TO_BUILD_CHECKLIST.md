# Vancomyzer Phase 1 Ready-to-Build Checklist

## Purpose
Define the final checklist that must be satisfied before actual Phase 1 page implementation begins.

## Build-ready standard
Phase 1 is ready to build only when:
- all five core page specs are finalized
- the shared asset bundle is finalized
- navigation and cross-linking are finalized
- claims/trust guardrails are finalized
- page-level asset selections are finalized
- implementation sequence is finalized

## Must-have items

### 1. Finalized page specs
The following documents must exist in refined/final form:

- reports/page-specs/VANCOMYZER_HOMEPAGE_IMPLEMENTATION_SPEC_REFINED.md
- reports/page-specs/VANCOMYZER_TRUST_EVIDENCE_IMPLEMENTATION_SPEC_REFINED.md
- reports/page-specs/VANCOMYZER_FAQ_IMPLEMENTATION_SPEC_REFINED.md
- reports/page-specs/VANCOMYZER_ABOUT_IMPLEMENTATION_SPEC_REFINED.md
- reports/page-specs/VANCOMYZER_CONTACT_INSTITUTIONAL_IMPLEMENTATION_SPEC_REFINED.md

### 2. Finalized page asset selections
The following documents must exist:

- reports/page-specs/VANCOMYZER_HOMEPAGE_ASSET_SELECTION.md
- reports/page-specs/VANCOMYZER_TRUST_EVIDENCE_ASSET_SELECTION.md
- reports/page-specs/VANCOMYZER_FAQ_ASSET_SELECTION.md
- reports/page-specs/VANCOMYZER_ABOUT_ASSET_SELECTION.md
- reports/page-specs/VANCOMYZER_CONTACT_INSTITUTIONAL_ASSET_SELECTION.md

### 3. Finalized shared asset bundle
This document must exist:

- reports/implementation/VANCOMYZER_PHASE1_ASSET_SELECTION_BUNDLE.md

This must lock:
- CTA family
- case mapping
- export mapping
- FAQ shortlist
- reuse rules

### 4. Finalized implementation structure
These documents must exist:

- reports/implementation/VANCOMYZER_PHASE1_SITEMAP_AND_NAVIGATION_REFINED.md
- reports/implementation/VANCOMYZER_PHASE1_CROSSLINKING_PLAN.md
- reports/implementation/VANCOMYZER_PHASE1_BUILD_SEQUENCE_REFINED.md
- reports/implementation/VANCOMYZER_PHASE1_ASSET_MANIFEST_REFINED.md

### 5. Finalized trust/claims guardrails
This document must exist:

- reports/trust-evidence/VANCOMYZER_VALIDATION_AND_CLAIMS_GUARDRAILS.md

This must be treated as required input during implementation.

### 6. Finalized MVP scope
This document must exist:

- reports/mvp-spec/VANCOMYZER_MVP_WEBSITE_SPEC_REFINED.md

This is the scope ceiling for Phase 1.

## Nice-to-have items
Helpful, but not required before build starts:

- builder brief refinement
- Cursor prompt variant refinement
- extra wording polish on non-critical pages
- secondary export file mapping notes
- post-build QA template

## Explicit blockers
Do not start implementation if any of these are unresolved:

- unclear homepage headline/subheadline choice
- unclear selected case mapping
- unclear selected export/example mapping
- conflicting CTA wording across pages
- missing guardrail document
- missing refined page spec for any core page
- unresolved navigation structure

## Ready-to-build decision rule
Phase 1 is ready to build when:
- all must-have items are present
- no explicit blockers remain
- scope remains limited to the 5 core Phase 1 pages

## Handoff readiness notes
Before coding begins, the builder should be able to answer:

1. What are the five pages?
2. Which case goes on each page?
3. Which export/example goes on each page?
4. What CTA family is used?
5. What trust/claims rules constrain the copy?
6. What is the exact implementation order?

If any of these cannot be answered from the docs, the project is not yet ready.

## Anti-scope-drift rule
Being “ready to build” does not mean “ready to expand.”
Do not add:
- SEO pages
- comparison pages
- resource hub
- newsletters
- lead magnets
- webinars
- outreach assets
before the 5 core pages are build-ready.

## Final readiness outcome
If this checklist is satisfied, the project can move from planning/refinement into direct Phase 1 implementation.
