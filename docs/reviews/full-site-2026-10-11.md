# Full-site source scan and es-ES editorial pass — 11 October 2026

## Scope and evidence

Inventory: **46 actual Next.js page routes**, 11,631 page-source lines, and 236 app/component/library files scanned by the repository localization inventory. The scan includes shared layouts/navigation/footer, forms, dialogs, accessible labels, inline width/grid constraints, generated-report presentation, 120 pre-existing numeric translation templates and the complete Spanish tutorial caption transcript. The source catalog was scanned in full for missing Spanish values, English identity/fallbacks, mixed-language words and literal/technical phrasing. Manual editorial review focused on the revised clinical copy, warnings, report prose, tutorial text and flagged candidates; this is not certification that every catalog sentence or possible API response has been reviewed clinically.

Supported locales remain **en, es, fr, pt-BR**. Terminology follows the AEMPS/SEFH glossary in [the previous Spanish review](spanish-2026-10-11.md): perfusión, pauta posológica, dosis de carga/mantenimiento, concentración medida, concentración pico/valle estimada, aclaramiento and estimación bayesiana. Sample timing remains measured from the start of the most recent perfusion. Scientific and legal claims were translated without changing their scope or uncertainty.

**This is not a new full live-site pass.** The Mac remains lock-blocked. Earlier Chrome evidence comprises 520 measurements across 26 public/signed-out routes (four locales × 320×740, 375×812, 390×844, 430×932 and 844×390), plus calculator/gate/interaction checks documented separately. The 18 protected routes redirected to login; their page bodies were not rendered. The pilot dashboard encountered its known error-response defect. Earlier screenshots and measurements predate these final text and authenticated-layout refinements.

Direct visual evidence remains the earlier calculator/settings/screenshots and partial Spanish Safari check. No new direct visual review was possible in this pass. No authenticated production account, real patient input, external form submission, payment, email, print or publication was used.

## Findings and fixes

- Replaced literal or awkward Spanish instructions with concise clinical wording; corrected the French word “bayésien” in a Spanish evidence description. Kept MAP/a priori terminology where it explains the method, while removing “motor” and “flujo” phrasing from the reviewed clinical text.
- Replaced the fragmented perfusion-start helper with one translated sentence. The timing validation message explicitly distinguishes administration from extraction and says the sample cannot precede perfusion start.
- Added localization to the previously unbound “Free” plan heading.
- Source-confirmed narrow-screen constraints corrected: viewport-bounded admin user drawer; responsive team invitation form; adaptive research summary/statistics/input/nephrotoxin grids; wrapping SCr rows; adaptive pilot phase/statistic grids and header. These are presentation changes only and are **not yet visually verified** with authenticated/synthetic states.
- Synthetic report HTML exposed missing labels and English dose-history/fit-quality/regulatory prose. Added catalog/templates for these cases, retaining numeric captures, units, dose-history distinctions and uncertainty. Refined long loading-dose explanations and fit-quality wording without changing eligibility, limits or calculation behavior.
- The known `/dashboard/pilot` issue remains: the page consumes an error JSON response without checking status/shape before accessing `status.trial.report_url`. No authentication, API or clinical behavior change was made in this pass.

The final source inventory has 3,238 catalog entries, 1,764 explicit static bindings and **zero missing bound translations**. This is not a translation-completeness percentage: 461 dynamic bindings and 1,164 child expressions remain separately inventoried. The 121 unbound candidates include scientific units/formulas, citations, product names, intended admin technical identifiers and shared-component props localized downstream (e.g. SidebarGroup and DetailSection titles). Those are not all untranslated defects. External/user-entered content is preserved, not machine-translated.
