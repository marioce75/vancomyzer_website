## Remaining issues and untested limits

1. Pre-existing `/dashboard/pilot` signed-out runtime error: a 401 response from trial status is treated as though `status.trial` exists, then `report_url` is read. Not changed in this layout patch.
2. Pre-existing date-state issue when expanding from one to two levels: the added level can visibly show today's date while lacking a collection timestamp; validation correctly rejects calculation. Explicit date selection resolves it. Manual elapsed-time mode succeeds. Calculation/timing logic was deliberately left unchanged.
3. No physical iPhone/Safari/Android browser, mobile virtual keyboard, safe-area/notch or screen-reader test. Chrome viewport emulation is not device equivalence. Browser zoom tested on desktop Chrome; application large text tested across all phone sizes.
4. No authenticated admin, research, account history/team/billing data; no payment, email, external submission, printer, deployment or production calculation used. FAQ/page layout was checked; not every possible accordion combination, tooltip hover state or error message was exercised.
5. Native tutorial controls/playback and caption source were checked; the full audiovisual narration and baked-in video UI were not re-recorded or comprehensively reviewed. See the Spanish audit for the remaining narration ambiguity.
6. Automated geometry checks exclude intentionally horizontally scrollable tables. They supplement visual review; they do not establish universal accessibility conformance.
