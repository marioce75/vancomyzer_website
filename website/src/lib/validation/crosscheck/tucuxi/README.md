## Model file

`vancomyzer.crosscheck.colin2019.tdd` — sha256
`49f6ebe6bcb31c79a919c4da0833a30bc6eb1113eb156e2377d80a2a6b67f925`.
Generated by `run_tucuxi.py` (the committed copy is the exact file used).

- Structural model: Tucuxi `linear.2comp.macro` (CL, V1, Q, V2), IV infusion.
- Covariate model: Colin 2019 Eqs 6–13 / Table 3 written as Tucuxi
  `softFormula` JavaScript on covariates `bodyweight` (kg), `age` (y) and `scr`
  (mg/dL) — i.e. Tucuxi evaluates the covariate equations itself; the typical
  values are **not** copied from Vancomyzer.
- BSV: `lognormal` (θ·e^η), ω = 0.35 / 0.25 / 0.50 / 0.50 (CL / V1 / Q / V2) —
  the same prior SDs as `fitPosteriorParameters.ts`.
- Residual error: Tucuxi `mixed`, σ0 = 1.0 mg/L, σ1 = 0.15:
  σ = √((0.15·pred)² + 1²). **Not identical in form** to Vancomyzer's
  σ = max(1, 0.15·max(obs, pred)). Both engines use Gaussian NLL with ln σ and
  the same prior penalty η²/(2ω²) (`Likelihood::negativeLogLikelihood`).

## Run

```
python3 run_tucuxi.py --tucucli <path>/tucucli --tucuxi-commit d09737e3
npx tsx ../compare.ts results/vancomyzer-2026-09-17.1-crosscheck-seed42-n200.json \
                      results/tucuxi-49f6ebe6bcb3-crosscheck-seed42-n200.json
python3 attribute_differences.py --threshold 3
```

Per patient: `.tqf` with a 60-dose q12h loop (1.5 h infusions; ≥ 12 terminal
half-lives even at t½ = 60 h), samples at 3.0 h and 11.5 h after the start of
the last dose, `aposteriori` prediction over the last interval with
`retrieveParameters` and `retrieveStatistics`. Posterior CL/V1/Q/V2 are read
from the last `cycleData`; peak/residual/auc from its statistics (response
unit µg/L converted to mg/L). Examples: `examples/p1.*`, `examples/p101.*`.
200/200 queries returned status 0; 54 s wall time.

## Attribution of the tail (every case ≥ 3 %)

`attribute_differences.py` refits the 14 patients with |Δ CL| ≥ 3 % with an
independent numpy/scipy MAP estimator (matrix-exponential steady state; shares
no code with either engine), once under each error-model form:

| id | Δ CL Vancomyzer vs Tucuxi | refit(V-form) vs Vancomyzer | refit(T-form) vs Tucuxi | form effect alone |
|---|---|---|---|---|
| p101 | +9.22 % | 0.00 % | 0.01 % | +9.22 % |
| p97 | +7.80 % | 0.00 % | 0.00 % | +7.80 % |
| p167 | +7.19 % | 0.00 % | 0.00 % | +7.20 % |
| p103 … p3 (11 more) | 3.3–6.8 % | ≤ 0.01 % | ≤ 0.01 % | = Δ |

Every tail case is reproduced to ≤ 0.01 % by the independent refit under the
matching σ form, and the entire difference is the σ form. All 14 are
`fit_quality: weak` cases where one observation is well above its prediction
(e.g. p101: 89.1 observed vs 66.0 predicted), which is exactly where
max(obs, pred) inflates Vancomyzer's σ relative to Tucuxi's pred-only √-form
and down-weights that level. No optimiser, convergence, boundary or
model-integration difference was found. Full table:
`results/attribution-….json`.

## What this does and does not show

- Shows: given the same prior and data, Vancomyzer's MAP estimator agrees with
  an independently implemented MIPD engine to < 1 % (median) on CL and V1, and
  the residual spread is fully explained by a documented, deliberate
  error-model design choice.
- Does not show: clinical validity of Colin 2019 for any population, the
  correctness of either error model, or agreement with commercial products
  (DoseMeRx, InsightRX, PrecisePK remain **BLOCKED**, see
  `docs/audit-2026-09-17/comparator-matrix.md`). Synthetic patients only.
- Open design question for clinical review (not changed here): whether the
  max(obs, pred) form — which reduces the influence of an unexpectedly high
  level — is the intended behaviour, since in the tail it moves CL by up to
  9 % relative to the additive-plus-proportional form.
